# bestseocompanydenverco.com

Denver SEO Buyer's Guide: a static site (GitHub Pages) explaining how to vet, compare and hire an SEO company in Denver in 2026. Published by Eye To Ad Media, disclosed on every page.

- No build step: plain HTML, one stylesheet (`/css/site.css`), one script (`/js/scorecard.js`).
- No external requests: system font stacks, inline SVG icons, no analytics.
- Custom domain via `CNAME`.
